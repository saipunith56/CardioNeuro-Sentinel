# Android Real Inference Migration Audit

This audit documents the current simulated/rule-based inference mechanisms in the CardioNeuro-Sentinel Android application and outlines the concrete target components that will replace them with on-device ONNX model executions.

---

## 1. Modality-by-Modality Audit

### 1.1 Cardiovascular Risk & Diagnostic
*   **CURRENT Simulation**: 
    - Calculated in `MultimodalInferenceEngine.kt#calculateCardiovascularRisk`.
    - Relies on simple mathematical threshold points: age (`(age - 60) * 0.8`), systolic BP (`(sysBp - 140) * 0.35`), cholesterol, smoker (`+12.0`), diabetic (`+10.0`), and troponin levels.
    - Presets map to hardcoded strings: `"ST Elevation MI"` adds `38.0` risk points, `"Atrial Fibrillation"` adds `28.0` points, and `"VTach"` adds `42.0` points.
*   **TARGET ONNX Inference**:
    - **Inference Wrapper**: `ClinicalDs2OnnxModel.kt` + `EcgOnnxModel.kt`.
    - **Tabular inputs**: Age, BP, Cholesterol, etc. scaling parameters matching training statistics inside `preproc_metadata_all.json["ds2"]`.
    - **Signal inputs**: The UI's selected ECG preset will map to standard 12-lead signal configurations loaded from the assets library. Preprocessing will perform 4th-order bandpass filtering and lead-wise temporal Z-scoring on a `[1, 12, 1000]` tensor.
    - **Inference execution**: `ds2_heart_model.onnx` and `ds4_ecg_model.onnx` run on a background thread pool.

### 1.2 Neurological & Stroke Risk
*   **CURRENT Simulation**:
    - Calculated in `MultimodalInferenceEngine.kt#calculateNeurologicalRisk`.
    - Uses rules: age (`(age - 55) * 0.7`), BP, diabetic (`+14.0`), family history (`+10.0`), and NIHSS score (`nihssScore * 3.5`).
    - Preset mappings: EEG preset `"Temporal Spike Wave"` adds `22.0` risk points and hardcodes seizure risk to `78%`. MRI preset `"Diffusion Weighted Imaging (DWI)"` adds `32.0` points and sets lesion volume to a heuristic function.
    - Toast subtype classification is a heuristic nested if-else chain.
*   **TARGET ONNX Inference**:
    - **Inference Wrapper**: `ClinicalDs3OnnxModel.kt` + `EegOnnxModel.kt` + `MriOnnxModel.kt`.
    - **EEG Signal**: EEG preset selections will map to representative `[1, 23, 256]` signal vectors loaded from assets. Standardized using channel-wise mean/std lists from `preproc_metadata_all.json["ds5_eeg"]`.
    - **MRI Image**: MRI preset maps to axial test images, decoded, resized to `128x128`, normalized with ImageNet statistics, and converted to `[1, 3, 128, 128]` CHW tensors.
    - **Inference execution**: `ds3_stroke_model_improved.onnx`, `ds5_eeg_seizure_model.onnx`, and `ds1_mri_stroke_model.onnx` run on a background thread pool.

### 1.3 Explainable AI (XAI) & Lesion Localization
*   **CURRENT Simulation**:
    - **SHAP**: Heuristically generated key-value pairs matching simple string lookups (e.g. if `troponin > 0.04f` we add a static `0.28f` impact item).
    - **LIME**: Completely static array of 5 criteria (`Systolic BP`, `ECG ST Segment`, `NIHSS Score`, `Troponin`, `Age Factor`) with hardcoded weights.
    - **Grad-CAM**: Returns predefined coordinates package: if `mriInfarct` is true, returns hardcoded regions centered at `(0.38, 0.42)` and `(0.62, 0.48)`.
*   **TARGET ONNX Inference**:
    - **SHAP / LIME**: Will be generated by calculating normalized feature attributions directly from the tabular scaling deviations. Since we are running the local models, feature impacts will reflect the actual scaled parameters of inputs relative to the means.
    - **Grad-CAM**: The axial MRI image classification wrapper will output actual probabilities. Heatmap displays will highlight the true detected stroke classification regions (Normal vs. Haemorrhagic vs. Ischemic) rather than static placeholders.

## 2. Component Migration Schematics

| Task Component | Current Simulated Provider | Target Real ONNX Provider |
| :--- | :--- | :--- |
| **Cardiovascular Risk** | Heuristics Points Calculation | `ClinicalDs2OnnxModel.kt` -> `ds2_heart_model.onnx` |
| **Arrhythmia Classification** | String presets ("Atrial Fibrillation" etc.) | `EcgOnnxModel.kt` -> `ds4_ecg_model.onnx` |
| **Stroke Risk** | Points + Heuristic Multipliers | `ClinicalDs3OnnxModel.kt` -> `ds3_stroke_model_improved.onnx` |
| **Seizure Probability** | Hardcoded preset mappings (eg: 78%) | `EegOnnxModel.kt` -> `ds5_eeg_seizure_model.onnx` |
| **MRI Infarct Classification** | Heuristic match on imaging type string | `MriOnnxModel.kt` -> `ds1_mri_stroke_model.onnx` |
| **Explainable AI (SHAP/LIME)** | Static lookup tables | Real-time feature weight scaling attributions |
| **Model Evaluation Details** | Hardcoded UI percentages | Dynamically fetched from assets JSON evaluation files |
| **Multimodal Fusion** | Max-of risk equation (+5 modifier) | Labeled evidence aggregation layer explicitly separating independent neural network outputs |

## 3. Scientific Limitations & UI Caveats
1.  **ECG & EEG Input Warning**: The application UI gathers string presets or simple single-lead waveforms. In the real layer, these must map to standard signal waveforms (e.g., standard 12-channel databases or 23-channel EEG montages) to run the models.
2.  **MRI Dataset Limitations**: MRI stroke classification is trained on only 16 patients. The UI must explicitly call this out.
3.  **Aggregate Fusion Disclaimer**: There is no joint multimodal fusion network. Individual risk percentages will be represented as separate indicators, with the overall score clearly documented as a heuristic clinical synthesizer summary, not a unified multi-modal network prediction.
